# 单词故事本 · 互联网互联化与社交打卡迭代方案 (方向 A)

> **目标**：基于 GitHub Pages 静态托管与免费 Serverless 数据库，将 `WowStory` 升级为具备 **离线 App 体验、多端云同步、金句打卡海报** 的互联网应用。

---

## 🏗️ 一、 零成本技术架构设计

由于项目采用 **GitHub Pages** 托管，不具备常规后端服务器，我们采用 **“纯静态前端 + 免费 Serverless 云存储”** 的无服务器架构：

```
+-------------------------------------------------------------+
|              GitHub Pages (静态托管 / 0 成本)               |
|                                                             |
|   - 故事页面 (Unit01~26.html)                               |
|   - 离线缓存脚本 (sw.js) --------> 负责 PWA 离线 / 秒开       |
|   - 海报生成脚本 (card.js) ------> 负责 浏览器本地画图         |
+------------------------------+------------------------------+
                               |
                               | (前端 JS SDK 异步调用)
                               v
+-------------------------------------------------------------+
|             Supabase (免费 Serverless 云数据库)               |
|                                                             |
|   - 微信 / 邮箱极简登录                                       |
|   - 存储用户的掌握度颜色、生词本数据 (免费层足够数万活跃用户)   |
+-------------------------------------------------------------+
```

*   **完全免买服务器**：运维开销为 0。
*   **不破坏单机优势**：断网时完全降级为 LocalStorage 本地存储，重新连网后后台自动补同步。

---

## 📱 二、 三大核心功能使用说明

### 1. 功能一：【离线使用与添加桌面应用 (PWA)】

*   **界面入口**：
    *   首次访问网站时，页面底部弹出提示条：`[ 📱 一键安装到桌面 | 即使断网也能读故事、听发音 ] [立即添加]`。
*   **使用步骤与效果**：
    1. **一键添加**：点击提示框中的 `[立即添加]`，手机或电脑桌面上生成 **WowStory 应用图标**，打开后无浏览器地址栏，享受原生 App 视感。
    2. **自动离线缓存**：联网打开任意单元（如 Unit 01），系统自动将当前单元的故事文本、考点卡与朗读音频下载保存在本地。
    3. **飞行/断网模式使用**：在无网环境下打开桌面应用，已学单元依然能流畅打开、高亮朗读发音。

---

### 2. 功能二：【多端登录与数据云端同步】

*   **界面入口**：
    *   顶栏右上角常驻状态按钮：未登录为 `[ 👤 登录同步 ]`，同步成功显示 `[ ☁️ 已同步 ]`。
*   **使用步骤与效果**：
    1. **一键登录**：点击右上角 `[ 👤 登录同步 ]`，使用微信扫码或快捷验证，1 秒完成登录。
    2. **后台静默同步**：背词时点击 `[记住]` / `[没记住]`，或把生词收入生词本，系统在 3 秒内自动在后台同步至云端（图标闪烁提示 `☁️ 同步中`）。
    3. **多端接续**：在手机、平板或另一台电脑登录同一账号，学习进度、掌握度颜色和生词本数据自动恢复，无需手动导入导出。

---

### 3. 功能三：【一键生成金句打卡海报】

*   **界面入口**：
    *   **读完故事**：故事文末按钮 `[ 📸 生成本篇金句卡 ]`。
    *   **测试完成**：结算面板按钮 `[ 🏆 生成通关海报 ]`。
    *   **每日打卡**：主页顶栏徽章 `[ 🔥 已连续打卡 X 天 ]`。
*   **使用步骤与效果**：
    1. **点击触发**：点击上述任意按钮，弹出海报预览弹窗。
    2. **选择海报样式**：
       * **【故事金句卡】**：展示本篇故事高分加分句式 + 目标考点词解析。
       * **【成就热力图卡】**：展示打卡连击天数 + 最近 30 天绿色学习热力图阵列。
    3. **保存与分享**：点击 `[ 💾 保存海报图片 ]`，前端 Canvas 生成高清 PNG 图片。移动端支持长按保存至相册，海报右下角带专属二维码，方便发朋友圈或研友群。

## 🗺️ 三、 实施阶段与测试标准

1. **Phase 1: PWA 离线支持** — 补齐 `manifest.json` 与 `sw.js`，实现基础 App 离线化。
2. **Phase 2: 打卡海报模块** — 编写 `card_generator.js`，实现纯前端 Canvas 绘制海报与保存。
3. **Phase 3: Supabase 账号与数据同步** — 前端接入 Supabase SDK，绑定 LocalStorage 拦截器实现无感云同步。
