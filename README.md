## 💡 为什么做这个：因为我们自己背词也想吐

**背单词最难受的不是「记不住」，是「记了没用」。**

死记硬背 `A-b-a-n-d-o-n` 放弃，背了 10 遍，阅读里遇到长难句依然蒙圈；死嗑词条释义，作文写出来的依然全是小升初词汇。孤立的词条就像没有灵魂的零件 —— 考试考的是这个词在句子里的行为：它跟什么介词搭、阅读里怎么被同义改写、作文里能不能升级替换。

所以这个项目换了条路：**把 26 个单元、1837 个必考词拆散重组**，每 12–20 个词编成一篇考研题材的英文小故事。词长在句子里，句长在故事里：

*   📖 **故事负责让你记住**：在看八卦、看法庭纠纷、看社会热点中自然记住词义与上下文搭配。
*   📇 **卡片负责让你会用**：每词配一张**五维考点卡**（核心搭配 / 近义替换 / 词族延伸 / 易混辨析 / 加分句式）。

## ⚡ 传统背词 vs 单词故事本

| 维度 | 传统背词 App / 词表 | 📖 单词故事本 WowStory |
|---|---|---|
| **记忆方式** | 孤立词条拼写 ↔ 释义硬记 | **121 篇考研题材英文小故事，语境自然浸入** |
| **考点深度** | 仅提供简单字典例句 | **每词配五维考点卡（含阅读同义改写与搭配）** |
| **写作输出** | 无法直接转化为写作素材 | **抽取加分句式生成【写】素材库，点按即发声** |
| **软件体验** | 广告多、逼你开会员付费 | **纯粹开源、零依赖、单个 HTML 双击秒开** |

## 🧩 五个功能：S T O R Y 闭环

五条链路的英文首字母，正好拼成本产品的主题词 **STORY**：

| 字母 | 功能 | 链路 | 我们是怎么做体验的 |
|---|---|---|---|
| **S** | **Story** | **读** | 按篇读故事，点加粗目标词即刻弹出考点卡；中文译文折叠在文末，展开/收起跨单元保存 |
| **T** | **Test** | **背** | 遮住释义翻卡自测；顶部词轨一格一词，颜色即掌握度（亮色即进度），背词读音**不读中文防泄底** |
| **O** | **Output** | **写** | 作文素材库，按加分句式出处检索，点一下就能听神经网络真人发音 |
| **R** | **Reference** | **查** | 全量速查表，支持英文 / 中文 / 词根三种搜法，点按展开完整考卡 |
| **Y** | **Yours** | **本** | 专属生词本。背词/读故事随手收录，自补发音，攒够一批开测 —— **这本是你的** |

## 🎨 极致的使用体验

*   🎧 **离线神经网络语音（Azure Neural TTS）**：
    *   3 个英文音色（女声亲切 / 男声明亮 / 男声沉稳）+ 1 个中文音色，随手调节语速与高亮滚屏跟读。
*   📱 **💻 电脑视角 / 📱 手机视角一键切换**：
    *   顶栏单按钮即时切换响应式排版，通勤路上用手机刷，图书馆用电脑读。
*   吸顶条常驻 **`Unit NN ▾` 矩阵**，选关跳转不必频繁返回首页。
*   零依赖、零后端：单个 HTML 双击就能跑，所有数据与偏好自动保存在本地。

## 快速开始

**前置条件**：Python 3.9 或更高（开发环境为 3.13）。只用于起本地服务器和生成音频 —— **浏览页面本身不需要 Python**。

```bash
git clone <你的仓库地址>
cd WowStory
```

然后起本地服务器：

- **Windows**：双击 `单词故事本/serve.cmd`
- **macOS / Linux**：`python3 单词故事本/serve.py`

浏览器会自动打开，默认 `http://127.0.0.1:8899`（端口被占用会自动 +1）。

```bash
python 单词故事本/serve.py --port 9000      # 换起始端口
python 单词故事本/serve.py --lan            # 局域网可访问，手机 / 平板能开
python 单词故事本/serve.py --no-browser     # 不起浏览器
```

### 补朗读音频

**仓库默认不含音频**（618 MB / 31,869 个文件，不适合进版本控制）。三种补齐方式：

```bash
# 1) 全量生成（默认 1–26 单元）
pip install edge-tts
python scripts/gen_all_audio.py

# 2) 只补某个单元
python scripts/gen_unit_audio.py 1

# 3) 在页面里补（生词本专用）
#    服务器在跑时：一键补生词发音
```
